# ブランド素材（マスコット・アイコンの元画像）

このフォルダの `mikan.png` が、アプリの**アイコン・スプラッシュ・アプリ内マスコット**すべての元画像です。
**本物のみかん画像を同じファイル名 `mikan.png` で上書き**すれば、以下すべてに反映されます。

| 反映先 | 生成物 | 用途 |
|---|---|---|
| アプリ内マスコット | `mikan.png` を直接表示 | ロゴ横・新規登録・ボトムナビ中央・楽しみ方 など |
| アプリアイコン | `assets/icon.png` | ホーム画面のアイコン（クリーム地・不透明／iOS用） |
| スプラッシュ | `assets/splash-icon.png` | 起動画面 |
| ファビコン | `assets/favicon.png` | Web |

## 差し替え手順

1. **透過PNG（背景透明）** のみかん画像を用意（正方形・512px以上推奨）
2. このフォルダに `mikan.png` という名前で上書きコミット
   - GitHub Web からでも可：`assets/brand/` を開き「Add file → Upload files」
3. アイコン類を再生成：

   ```bash
   node scripts/gen-icons.mjs      # mikan.png から icon / splash / favicon を生成
   ```

4. アプリ内マスコットは `mikan.png` を直接参照しているため、差し替えるだけで反映されます

> 現在は暫定として、みかんを忠実にベクター再現した画像が入っています。
> 本物の画像に差し替えると、アイコンもマスコットも実画像ベースになります。
