# 商品写真スロット

このフォルダの画像は、アプリの商品サムネイル／詳細で使われます。
**実写真を同じファイル名で上書き**すれば、コードを変えずにアプリ全体へ反映されます。

| ファイル名 | 割り当て商品 | カテゴリー |
|---|---|---|
| `switch.jpg` | Nintendo Switch | ゲーム・おもちゃ |
| `iphone.jpg` | iPhone 15 | スマホ・家電 |
| `airpods.jpg` | AirPods Pro | スマホ・家電 |
| `bag.jpg` | ルイヴィトン バッグ | レディース |
| `controller.jpg` | ワイヤレスコントローラー | ゲーム・おもちゃ |
| `books.jpg` | 文庫本 まとめ売り | 本・音楽 |

## 差し替え方法

1. 上記のファイル名（拡張子 `.jpg` のまま）で写真を用意する
2. このフォルダに同名で上書きコミットする
   - GitHub の Web からでも可：リポジトリの `assets/products/` を開き
     「Add file → Upload files」でドラッグ＆ドロップ → Commit
3. プレビュー（Web）は再ビルドで反映。実機（Expo Go）はリロードで反映

> 正方形（推奨 800×800 以上）だと綺麗に表示されます。別の商品にも割り当てたい場合や
> ファイル名を変えたい場合は `src/data/mock.ts` の `P`（写真マップ）を調整します。
