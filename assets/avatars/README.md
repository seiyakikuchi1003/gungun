# ユーザーアバター

各ユーザーのアイコン。現在は**自動生成のグラデ＋イニシャル**が入っています。
実写真に差し替えたい場合は、同じファイル名で上書きしてください（正方形・256px以上推奨）。

| ファイル名 | ユーザー |
|---|---|
| `takusan.png` | たくさん |
| `sakura.png` | さくら |
| `yu.png` | ゆう |
| `haru.png` | はる |
| `metan.png` | めたん（ログイン中ユーザー） |
| `kenta.png` | けんた |

## 実装メモ

現在アバターは、確実な表示のため **data URI 文字列**として `src/data/avatarData.ts` に埋め込んでいます
（元画像は上記PNG）。PNGを差し替えたら `avatarData.ts` を再生成すると反映されます。

> 本実装（ネイティブ）では、アバターはユーザーがアップロードした画像URL（Supabase Storage）を
> `Avatar` コンポーネントに渡す形になります。ここはモック用の暫定データです。
