## 説明文（4000文字以内）

```
「ぐんぐん」は、お金を使わずにモノとモノを交換するアプリです。

使わなくなったけれど、捨てるには惜しい。
そんなものを「タネ」として植えると、それを欲しい誰かが自分の持ち物を差し出して「水やり」してくれます。
集まった中から欲しいものをひとつ選べば、交換が成立します。

わらしべ長者のように、小さなものから思いがけない出会いが生まれる。
それが「ぐんぐん」の楽しみ方です。


■ 使い方はかんたん3ステップ

1. タネを植える
　使わないものを写真と一緒に出品します。

2. 水やりが集まる
　あなたのタネを欲しい人が、自分の持ち物を差し出してくれます。

3. 収穫する
　集まった中から欲しいものをひとつ選ぶと交換が成立。あとは発送するだけです。


■ 交換の「輪」ができる

ぐんぐんの交換は1対1ではありません。
AさんのものがBさんへ、BさんのものがCさんへ、CさんのものがAさんへ。
一周してつながる「輪」ができるので、必ずしも相手が欲しがるものを持っていなくても交換できます。

全員の受け取りが終わると、誰から誰へ何が渡ったのかを1枚の画面で振り返れます。


■ 安心して交換するために

・取引画面で「今どの段階か」「次に何をすればいいか」が常にわかります
・発送前のチェックリストで、梱包や宛先の確認をうながします
・配送業者と追跡番号を登録でき、受け取る側は配送状況を確認できます
・取引が終わったら、お互いを評価します
・気になる出品や投稿は通報でき、特定の相手をブロックすることもできます
・お届け先の住所は、あなたに商品を発送する相手にだけ表示されます


■ 掲示板でつながる

「こんなものを探しています」「交換できました」など、
利用者どうしで気軽にやり取りできる掲示板があります。


■ 肥料について

水やりをするには「肥料」を使います。
肥料は毎日のログインボーナスで受け取れるほか、アプリ内で購入することもできます。
プレミアムに登録すると、毎日受け取れる肥料が増えます。


捨てるのはもったいない、でも売るほどでもない。
そんなものに、次の持ち主を見つけてあげてください。
```

### 備考（Notes）

```
【アプリの概要】
本アプリは、利用者どうしが不要になった物品を金銭のやり取りなしに交換するサービスです。
出品（タネを植える）→ 他の利用者が自分の持ち物を差し出す（水やり）→
出品者が欲しいものを選ぶ（収穫）→ 発送・受け取り・評価、という流れで交換が成立します。

【動作確認の手順】
1. 上記のアカウントでログインしてください。
2. ホーム画面に他の利用者の出品が並びます。商品を開き「水やりする」から
   ご自身の持ち物を差し出す流れをご確認いただけます。
3. 画面下部の「収穫」タブに、ログインしたアカウントの出品と、集まった水やりが表示されます。
   商品を選ぶと交換が成立し、「取引」タブに取引が現れます。
4. 「取引」タブの取引を開くと、発送 → 受け取り → 評価 の各段階を確認できます。
   発送・受け取りの操作はどちらもこの画面から行えます。
5. 通知一覧に「輪が完成しました」という通知があります。開くと、
   誰から誰へ何が渡ったのかをまとめた画面が表示されます。

【ユーザー生成コンテンツへの対応】
・出品、掲示板の投稿、コメント、利用者のいずれも、画面内の「…」メニューから通報できます。
・利用者をブロックすると、その相手の出品・投稿は表示されなくなります。
・利用規約で、わいせつ・暴力的・差別的な内容および迷惑行為を明確に禁止しています。
・通報を受けた内容は運営が確認し、24時間以内に削除・利用停止を含む措置を行います。
・アカウントは「マイページ → 退会」からアプリ内で削除できます。

【アプリ内での支払いについて】
アプリ内の「肥料」の購入とプレミアム登録は、現在 Stripe による決済を実装しています。
Apple のアプリ内課金への対応方針について、ご指摘があればご教示ください。
交換される物品そのものは実物であり、利用者間で金銭のやり取りは発生しません。
```
