# 提出後に想定しておくこと

**Stripe決済で差し戻される可能性が高い**（ガイドライン3.1.1／デジタルコンテンツはApple課金必須）。
審査メモに事前説明を入れてあるので、Appleの返信をそのまま共有してください。

差し戻された場合の選択肢：

1. 肥料チャージとプレミアムを iOS から一旦隠して再提出（最短）
2. Apple のアプリ内課金に作り替える
   → App Store Connect での商品登録・税務・銀行情報の登録が必要（めたん様の作業）

# 余裕があるときに

- 公式サイトに**利用規約のページがない**（`/terms` が404）。
  アプリ内には全文あり。Web用の本文 → https://gungun-app.pages.dev/legal/terms
- **特定商取引法に基づく表記**（有料機能があるため日本の法令上必要）
  → https://gungun-app.pages.dev/legal/tokushoho
  事業者名・所在地・電話番号は「請求があれば開示」としてある。確定したら差し替え
