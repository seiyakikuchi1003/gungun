###### 直したもの

**① ニックネームが「名無し」／画面ごとに違う**

`getUser()`（モックデータ）が、見つからない id に `{ nickname: '名無し' }` を返していました。実データでは id が UUID なのでモックに当たらず、**通知・コメント・ブロック一覧・ツリーなど14ファイルが全部これを踏んでいました**。

「個人情報では別の名前が出る」は別の原因で、**個人情報設定の画面がニックネーム「めたん」・メール「demo@gungun.app」を決め打ちで表示**していました。実データに差し替え、お届け先・電話番号も `addresses` から出すようにしました。マイページの評価も 4.5 固定をやめて実データにしています。
