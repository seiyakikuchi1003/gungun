理由を公式ドキュメントで確認しました。考えられる原因は2つで、状況からするとおそらく①です。

###### ① セッションの公開設定が「Team」になっている（最有力）

Team / Enterprise プランでは、Claude Code のセッションごとに公開範囲が **Private（自分だけ）/ Team（組織の全メンバー）** の2択があります。

> Team visibility makes the session visible to other members of your claude.ai organization.
> （Team 表示にすると、同じ claude.ai 組織の他のメンバーからセッションが見える）

- **通常のチャットは常に本人だけ**なので、「Claudeコードのセクション**だけ**みんなに見える」という今の症状と一致します
- セッション作成時の既定や過去の共有操作で Team になっている可能性があります
- ちなみに **Slack 連携から作ったセッションは自動的に Team 共有**になる仕様です

###### 非公開にする方法
1. claude.ai/code で該当セッションを開く
2. **共有（Share）/ 公開範囲**の切り替えで **「Private」** に変更
3. 既定の挙動や名前の表示は **Settings → Claude Code → Sharing settings** で調整できます

###### ② そもそも同じアカウントを共用している場合

このセッションのアカウントは `ai@souzoh-official.com` という**共用っぽいアカウント**です。もし複数人がこのアカウント自体にログインしているなら、チャットもコードも全部同じものが見えます（それはアカウント共有の当然の結果です）。ただ「コードのセクションだけ」という話なら、これではなく①が原因です。

---

**まとめ**：Claude Code のセッションには「Team に公開」という独自の可視性設定があり、それが有効になっているためです。各セッションの共有設定を **Private** に切り替えれば、他のメンバーからは見えなくなります。逆に、今回のように開発の様子をチームで追いたい場合は Team のままにしておく使い方もアリです（先方共有はせず、社内レビュー用として）。
