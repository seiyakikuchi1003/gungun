# ★フェーズ1：取引詳細画面（最優先・前回未反映）

## 8. 相手との取引画面が「全く作られていない」→ 作り込む
- 前回（8/12・項目10）で「取引詳細画面を作る」と指示したが、**全く反映されていない**。作り直す。
- 「取引」を押したら、以下が見られる**取引詳細画面**を作る：
  - 相手（誰と取引しているか）
  - その商品（画像・商品名・商品の状態）
  - **相手の住所・自分の住所**
  - 取引の進行段階
- **前回MDに落とした Re tool の作りを真似る**（`docs/gungun-retool-adopt.md` の 1-5：ActionCard＋ステッパー方式）。
  - ステッパー：収穫→発送→受取→評価→完了
  - ActionCard：ステータス×役割で「次にやる操作＋ボタン」を1枚に。自分の番/相手待ち/完了で色分け。
  - 取引詳細から取引メッセージへ（参加者のみ・Realtime）。
  - **レンタル固有（返却・日程・手数料）は取り込まない。**
- **取引画面がまだほぼ無いので、ここを中心に作り込む。**

# フェーズ2：収穫・評価まわりのバグ

## 5. 受け取り報告が「受け取りを記録できませんでした」になる
- 受け取りを報告した後、時々「受け取りを記録できませんでした」と出る。**確実に受け取りが記録される**ように直す。

## 6. 評価後にまた評価できてしまう（DB未反映）
- 受け取り→評価して「評価完了」ポップアップが出たのに、**再度評価できてしまう**。
- 原因：評価がデータベースに反映されていない。評価を確実に保存し、**一度評価したら再評価できない**ようにする（1取引1人1回）。

## 7. 「評価を送信しました」画面のボタンがくっついている
- 「みんなの輪を見る」ボタンと「取引一覧に戻る」ボタンがくっついていて変。**間隔を空けて綺麗なデザイン**にする。

# フェーズ3：ホーム・水やり表示

## 1. ホームに水やりされた商品が出ていない → 全商品出す
- ホームの商品一覧が**種の商品しか並んでいない**。水やりされた商品（種に結びついた商品）が出ていない。
- **水やりされた商品も含め、すべての商品がホームに出る**ようにする。
  - ※水やり＝出品なので、水やりで出した商品も一級の商品としてホーム・一覧に出る（要件 第3章）。

## 2. 「もっと水やりをする」ボタンが不要 → 作り直す
- 種に水やりした後にその種を見に行くと「もっと水やりをする」ボタンが出るが、**1つの種には1度しか水やりできない**ので不要。
- このボタンを出さないようにする（1木1回ルールに合わせる）。

---

# フェーズ4：出品・写真

## 3. 写真を追加すると「容量が多くて投稿できません」→ 直す
- 写真を5枚・1枚以上追加すると「容量が多くて投稿できません」と出る。
- **最大10枚まで投稿できる仕様**なので、10枚まで問題なく投稿できるように直す（アップロード時の圧縮・上限を見直す）。

## 4. 投稿時に写真を編集（切り抜き・トリミング）できるように
- 投稿時、写真のサイズなどを少し編集できるようにする。**切り抜き・切り取り（トリミング）**をできるように。
  - ※CRM登録済みの「写真編集（トリミング）機能」と同件。

## 補足（仕様として確認済み）

- **水やり＝出品**。水やりした商品もホーム・一覧・検索に出る（要件 第3章）。
- **1つの種には1度だけ水やり**。「もっと水やりをする」は不要。
- **1取引1人1回評価**。評価はDBに確実に保存し、再評価不可に。
- **取引詳細画面**は Re tool の ActionCard＋ステッパー方式（`docs/gungun-retool-adopt.md` 1-5）。レンタル固有は取り込まない。
