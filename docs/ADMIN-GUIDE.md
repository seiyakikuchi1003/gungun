# 管理画面の使い方

運営（めたん様チーム）が日々使う画面です。**アプリを作り直さずに、金額・肥料量・規約を
変更できる**ことがこの画面の一番の役目です。

## 開き方

| 場合 | URL | パスワード |
|---|---|---|
| 手元で確認する | http://localhost:3100（`npm run preview` で立ち上がる） | 不要 |
| 公開URL | https://gungun-admin.pages.dev | 必要（`ADMIN_PASSWORD`） |

- パスワードは共有1本です（運営が数人の想定）。Cookie にはパスワードそのものではなく
  ハッシュを入れています。
- `ADMIN_PASSWORD` が未設定のとき、**localhost 以外からは 503 で閉じます**。
  裏に全権限のキーがあるため、鍵なしで通すより閉じる方を選んでいます。
- 左下に **「● Supabase 接続中」** が出ていれば実データを見ています。

> **運営の操作はすべて `admin_audit_log` に記録されます**（誰が・いつ・何を）。
> 引き継ぎ後も追えるようにするためです。

## ダッシュボード

いま見るべき数字だけを7つ並べています。カードを押すと該当ページに飛びます。

| カード | 中身 | 見かた |
|---|---|---|
| ユーザー | 登録者数 | 退会した人は含みません |
| プレミアム | 課金中の人数 | オレンジ表示 |
| 種（ツリーの起点） | 誰かに水をやられていない出品 | 森に新しく生えた木の数 |
| 育成中の商品 | 交換前の出品 | 緑表示 |
| 収穫された種 | 成立した収穫の回数 | 取引が生まれた回数 |
| **未対応の通報** | 未処理の通報 | **1件でもあると赤くなります。ここだけは毎日見てください** |
| 掲示板の投稿 | 投稿数 | — |

下段に「最近の出品」「最近の登録」が各8件出ます。日時は日本時間です。

## ユーザー

ニックネームで検索できます（最大100件）。

| 列 | 内容 |
|---|---|
| ニックネーム / 肥料 / プレミアム / 状態 / 登録日 | 一覧 |
| 操作 | 肥料の増減、利用停止／解除 |

### 肥料を付与・減算する

数字を入れて「肥料付与」。**マイナスも入れられます**（`-100` で減算）。

- 残高は 0 未満にはなりません
- **`fertilizer_ledger` に `admin` として必ず記録**されます。あとから「なぜ増えたか」を追えます
- お問い合わせ対応（不具合で肥料が消えた等）のお返しに使います

### 利用停止する

理由を書いて「利用停止」。解除も同じ場所です。

停止された人にできなくなること／できること：

| | 状態 |
|---|---|
| 出品（タネを植える） | ✗ できない |
| 水やり | ✗ できない |
| 収穫 | ✗ できない |
| ログイン・閲覧 | ○ できる（設計どおり） |
| **掲示板への投稿・コメント** | **○ できてしまう（未対応。下記参照）** |

- 理由は運営側の記録用で、ユーザーには出ません
- 荒らし対応で掲示板を止めたい場合は、いまは**投稿を個別に消す**か
  商品側で対応してください。DB 側で塞ぐ改修が残っています（`NEXT.md` C-6）

## 商品

商品名で検索、上のタブで絞り込みます。

| タブ | 中身 |
|---|---|
| すべて / 種のみ / 育成中 / 交換中 / 削除済み | 状態での絞り込み |

| 列 | 意味 |
|---|---|
| **段** | ツリーの深さ。**0 = 種（起点）**、1 = 種に水をやった人、2 = さらにその先 |
| **ツリー** | どの木に属しているか（起点の ID の頭8桁） |
| 状態 | 育成中／交換中／交換済み／削除済み |

### 「非表示」と「復活」

- **物理削除はしません。** `status` を `deleted` にして隠すだけです。
  ツリーの親子関係（誰が誰に水をやったか）が壊れると森の履歴が失われるためです。
- 「復活」を押すと **育成中** に戻ります（交換中には戻りません）。
- 非表示にしたものは「削除済み」タブから探せます。

規約違反の出品を見つけたら、**通報の対応より先にここで非表示**にするのが早いです。

---

## 通報

タブは 未対応 / 対応済み / 却下 / すべて。既定は **未対応**です。

1件ごとに、通報された対象（商品名・投稿本文・ユーザー名）、通報者、理由、日時が出ます。

| ボタン | 使うとき |
|---|---|
| **対応済みにする** | 実際に対処した（商品を非表示にした、ユーザーを停止した など） |
| **却下** | 見たが問題なしと判断した |
| 未対応に戻す | 判断をやり直したいとき |

**対応メモ**（任意）を入れておくと、あとから「なぜそう判断したか」が残ります。
複数人で運営する場合、ここを書く習慣にしておくと重複対応を防げます。

> C2C アプリは App Store の審査で「トラブル時の窓口と通報の仕組み」を見られます。
> この画面が機能していること自体が審査対策になります。

## アプリ設定 ★これが一番重要

`app_settings` の値をここから直接変えます。**保存すると次にアプリがデータを取り直した
タイミングで反映されます。アプリの更新・再申請は不要です。**

| キー | 意味 |
|---|---|
| `water_cost` | 水やり1回に使う肥料 |
| `daily_login_bonus` | ログインボーナス（通常会員） |
| `daily_login_bonus_premium` | ログインボーナス（プレミアム） |
| `first_seed_free` | 初回の出品を無料にするか（`true` / `false`） |
| `premium_price_yen` | プレミアム月額（円） |
| `seed_price_yen` | 2回目以降の出品料（円） |
| `max_images_per_item` | 商品写真の上限枚数 |
| `terms_of_service` | **利用規約の本文**（改行そのまま） |
| `privacy_policy` | **プライバシーポリシーの本文** |

- 数字は数字として、`true` / `false` は真偽値として保存されます（アプリ側が型を見ています）
- 規約・ポリシーは長文をそのまま貼れます。課金対応で差し替えるときもここです
- 最終更新の日時が右に出ます

> **バランス調整の目安**：水やりが重すぎると森が育たず、軽すぎると収穫が雑になります。
> `water_cost` と `daily_login_bonus` は「1日に何回水をやれるか」で決めるのが分かりやすいです
> （例：ボーナス 40 ／ 水やり 10 なら 1日4回）。

## やらないほうがいいこと

| すること | なぜ |
|---|---|
| Supabase の Table Editor で `items` の行を直接消す | ツリーの親子関係が壊れます。管理画面の「非表示」を使ってください |
| `app_settings` のキー名を変える | アプリが読めなくなります。値だけ変えてください |
| service_role キーを人に渡す・チャットに貼る | 全ユーザーの個人情報を読み書きできる鍵です |
| `ADMIN_PASSWORD` を未設定のまま公開URLを共有する | 503 で閉じるので誰も入れません（安全ですが使えません） |

   （Cloudflare Pages → gungun-admin → Settings → Variables → 編集 → Deployments → Retry deployment）

3. お客様アカウントへ移す手順は [`NEXT.md`](./NEXT.md) の E 章
