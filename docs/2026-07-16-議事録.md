## 2. アプリ概要（前提の再確認）

「ぐんぐん」は、**わらしべ長者**をモチーフにした C2C 物々交換アプリです。
「植物を育てる」というメタファーで、交換の一連の流れを直感的に表現しています。

| 用語 | 意味 |
|---|---|
| 🌱 タネを植える | 商品を出品する |
| 💧 水やりする | 欲しい商品に「交換希望」を出す（肥料を消費） |
| 🍊 収穫する | 交換を成立させる（玉突き交換の輪ができる） |
| 肥料 | アプリ内ポイント（ログインボーナス・チャージで獲得） |

- 商品同士が「木構造（ツリー）」でつながり、収穫時に**玉突き交換の輪**が成立するのが最大の特徴。
- ブランドカラーは **グリーン × オレンジ**、マスコットは**みかん**。
- 対象プラットフォームは **iOS（Expo / React Native）**。

## 4. デザインの方向性（今回の決定・確認ポイント）

- **世界観**：やわらかい角丸ゴシック（M PLUS Rounded 1c）＋クリーム背景で、親しみやすく最新のアプリらしい雰囲気に統一。
- **マスコット**：みかん・じょうろを実画像ベースで採用し、要所で登場させて世界観を演出。
- **主要導線**：出品（タネを植える）はホーム右下のラベル付きボタンで、初めての人でも迷わない設計。
- **商品画像**：実写真を配置し、完成イメージに近い見え方を確認可能に。

> ✅ **本日ご確認いただきたい点**
> - 全体のトーン＆マナー（色・フォント・余白）でよいか
> - 各画面のレイアウト・導線に違和感がないか
> - 追加・修正したい画面や要素はあるか

## 5. 技術スタック（実装方針）

| 領域 | 採用技術 |
|---|---|
| アプリ | Expo（React Native）/ TypeScript ／ **iOS のみ** |
| DB・認証・ストレージ | Supabase（PostgreSQL） |
| 管理画面 | Next.js + Tailwind ／ Cloudflare Pages |
| メール | Resend（認証コード・一斉送信） |
| 決済 | Stripe（Apple Pay。**金額・導線は差し替え可能な設計**） |
| プッシュ通知 | Expo Notifications |
